
Un sistema de búsqueda resuelve un problema encontrando una secuencia de acciones qu lleva de un estado inicial a un estado meta.
- Estado inicial: dónde empieza el agente
- Acciones: que puede hacer en cada estado
- Modelo de transición: a qué estado llega después de cada acción
- Prueba de meta: como sabe que ya llegó
- Costo del camino: cuánto cuesta cada acción y la secuencia completa

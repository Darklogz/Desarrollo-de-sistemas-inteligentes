
Entidad que percibe su **entorno** mediante sensores (o datos) y actúa sobre ese entorno mediante actuadores, seleccionando en cada momento la acción que maximiza su medida de desempeño, dado lo que ha percibido hasta ese punto y el conocimiento con el que cuenta.

¿Qué es un sistema inteligente?

| Tipo de agente           | Sensor                   | Actuador                 |
| ------------------------ | ------------------------ | ------------------------ |
| Robot aspiradora         | Cámara, sensor de choque | Motores de las ruedas    |
| Termostato programable   | Sensor de temperatura    | Relé que prende/apaga    |
| Corrector ortográfico    | El texto que escribes    | Subrayado que dibuja     |
| Filtro de spam           | El correo entrante       | Mover a bandeja de spam  |
| Sistema de recomendación | Tu historial de clics    | La lista que te muestra  |
Clasificacion #1
- Los agentes se clasifican según cuánta información usan para decidir: solo lo que perciben ahora, un modelo del mundo, una meta, o una medida de qué tan bueno es cada resultado posible
- Reflejo simple: decide solo con la percepción actual, sin memoria
- Basado en modelo: mantiene un estado interno de como es el mundo, aunque no lo vea todo
- Basado en objetivos: evalúa acciones según si lo acercan a una meta
- Basado en utilidad: compara resultados posibles y elige el de mayor valor
- De aprendizaje: mejora su propia función de decisión con la experiencia

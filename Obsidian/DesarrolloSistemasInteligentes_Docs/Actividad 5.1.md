Ingeniería de software
1. Comunicación: entrevistas, visitas, encuestas, investigación de aplicaciones
Etapa inicial en la que se establece el diálogo entre el cliente y el equipo de desarrollo para comprender el problema y entender qué se necesita construir. Cómo funciona: Se realizan entrevistas, reuniones y levantamiento de requerimientos para identificar los objetivos, las necesidades del usuario y los alcances del proyecto. Caso de uso: Una reunión inicial con el dueño de un restaurante para definir qué platillos quiere mostrar en su nueva aplicación de entregas a domicilio.
2. Planeación: metodologías ágiles, scrum, kanban, programación XP, itinerario
Fase de organización estratégica en la que se define el mapa de ruta, los tiempos, los recursos y los costos necesarios para ejecutar el proyecto. Cómo funciona: Se desglosa el proyecto en tareas pequeñas, se asignan responsabilidades al equipo, se crea un cronograma de trabajo y se evalúan los posibles riesgos. Caso de uso: La creación de un calendario de trabajo detallando que el diseño tomará 2 semanas, la programación 6 semanas y estimando el costo total de los servidores.
3. Modelado: diagramas UML
Etapa de diseño conceptual y visual donde se crean diagramas y bocetos que representan cómo estará estructurado el sistema antes de escribir código. Cómo funciona: Se dibujan las arquitecturas del software, los diagramas de flujo de datos, la estructura de la base de datos y los bocetos de las pantallas (_wireframes_ o _mockups_). Caso de uso: Diseñar en una herramienta visual (como Figma) el aspecto que tendrán las pantallas de inicio de sesión y el carrito de compras antes de programarlas.
4. Construcción
Fase de ejecución en la que se traduce el diseño a código ejecutable y se verifica que no tenga errores. Cómo funciona: Los desarrolladores escriben el código fuente en los lenguajes seleccionados y realizan pruebas técnicas para detectar y corregir fallos de funcionamiento. Caso de uso: Programar en Python o JavaScript la lógica que procesa el pago con tarjeta de crédito y verificar que el dinero se descuente correctamente.
5. Despliegue
Etapa de entrega en la que el software terminado se pone a disposición de los usuarios finales en su entorno de uso real. Cómo funciona: El sistema se instala en servidores web, la nube o tiendas de aplicaciones, y se inicia la fase de soporte y retroalimentación para futuras mejoras. Caso de uso: Publicar la aplicación en la Google Play Store y App Store para que los clientes puedan descargarla e instalarla en sus teléfonos.
